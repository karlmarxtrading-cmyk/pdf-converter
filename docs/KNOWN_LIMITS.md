# Batas yang perlu diketahui pengguna RC12

- Nama penyedia AI belum cukup untuk menentukan kompatibilitas. Hasil paste bergantung pada kedua MIME di clipboard, struktur wrapper, browser dan OS. Periksa rumus ambigu pada pratinjau.
- PDF menggunakan mesin cetak browser dan font lokal/tersemat yang disediakan aplikasi. Pilihan ukuran halaman, margin, header dan skala di dialog dapat mengubah paginasi. File PDF hasil otomasi, PDF dari dialog sistem dan bukti pada Windows dicatat terpisah.
- Teks, jumlah blok dan akhir naskah dapat diperiksa secara menyeluruh. Penilaian visual glif dan tata letak berlaku pada halaman yang diperiksa. Karakter privat tanpa pemetaan memerlukan keputusan pengguna.
- Bentuk satu paragraf, tabel panjang, banyak heading dan paragraf terpisah diuji masing-masing. Kapasitas perangkat serta beban browser tetap berpengaruh. Simpan cadangan proyek asli bila proses cetak berakhir dengan diagnosis.
- Penyimpanan editor terkait dengan origin browser. Sebelum pindah origin, menghapus data atau melakukan rollback, unduh cadangan .pfproj dan uji pemulihannya.
