# Bukti audit RC4

Keputusan aktif: repository/docs/RELEASE_REPORT.md. final/ berisi pemeriksaan kode/build/gate/HTTP pada kandidat akhir. cleanroom/ berisi instalasi dan rekonstruksi independen dari arsip kandidat. performance-core-final.json terikat hash kandidat; snapshot-performance.json adalah pengukuran pendukung terdahulu atas implementasi snapshot yang sama, tanpa fingerprint seluruh kandidat saat pengukuran (batasnya dijelaskan di laporan performa).

Data before/after dan laporan domain dipertahankan untuk menunjukkan reproduksi, termasuk kegagalan sebelum patch. final-before-e2e-assertion-hardening/ adalah checkpoint sebelum perubahan tes terakhir, bukan hasil kandidat final. candidate-build.log menangkap guard yang menolak source berubah saat build awal; build final yang stabil lulus. baseline-unit.log mempunyai dua kegagalan resolusi Vite karena setup symlink dependensi lintas direktori; baseline-unit-recheck.log memakai npm ci mandiri dan 255/255 lulus. baseline-build.log berasal dari upaya sementara yang salah metadata; baseline-build-restored.log dan baseline-dist-rebuild.json adalah baseline source RC3 yang benar dan 281/281 dist identik.

cleanroom-incomplete-preparation/ merekam kekeliruan penyusunan arsip validasi sementara: filter folder docs terlalu luas sehingga public/docs/panduan.html terlewat. Verifier statis menolak paket itu. Filter diperbaiki menjadi root-only dan fingerprint source diperiksa sebelum instalasi; cleanroom/ adalah ulangan pada direktori baru dengan paket sumber lengkap. Tidak ada cacat itu yang disembunyikan sebagai PASS.

final/browser-attempt.log adalah percobaan kandidat akhir yang gagal meluncurkan Chromium (socket/ptrace tidak diizinkan); tidak ada skenario browser yang diklaim lulus. PDF historis yang ditinjau visual berada di render_exports/pdf-visual-history dan jelas berlabel RC3. PDF laporan audit dibuat dengan ReportLab sebagai penjelasan audit, bukan keluaran mesin PaperForma.

Log dapat memuat path workspace pengujian. File .private, kredensial, helper penyimpanan, node_modules dan browser profile tidak disertakan. Reproduksi benchmark membutuhkan ekstraksi ZIP RC3 asli sebagai baseline; kode baseline tidak dimasukkan dua kali ke paket deploy baru.
