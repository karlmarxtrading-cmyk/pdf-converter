# Pengukuran pada kandidat terdahulu dalam pekerjaan RC8

Direktori ini menyimpan data mentah dan keputusan kandidat sebelum optimasi DOM dan paginasi. Identitas source dan distribusi lengkap ada di start.json. Dua cohort Chromium awal terhenti. Pengambilan data tambahan menyimpan seluruh 240 pasangan terjadwal beserta dua lengan yang gagal dalam satu pasangan. Laporan performa memuat keterangan per percobaan. Versi akhir menggunakan putaran terpisah di evidence/rc8/acceptance dan evidence/rc8/performance.
