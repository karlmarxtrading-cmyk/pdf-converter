# Verifikasi sebelum pembekuan

`g09-prerequisites.json` mencatat identitas ZIP pembanding RC6, manifest internal, source, dist, lockfile, data mentah historis RC10 dan checksum prosedur. Angka pada bagian `prior` hanya berlaku pada RC10. File `font-test.log` mencakup pemeriksaan buffer font yang dipakai ulang dan diubah pemanggil. File `oracle-preflight.log` menguji bahwa perubahan konten/representasi pada HTML acuan dapat dideteksi dengan jumlah rumus yang tetap. Hasil masing-masing cohort kandidat tersimpan di direktori induk setelah pengukuran.
