# Pengujian alat penerimaan eksternal pada Linux

Putaran aktif tercantum pada frozen-external-adapter-init.json. Collector G12–G16 mengikat kelima formulir kosong ke identitas yang sama. Formulir dipakai nanti pada perangkat dan layanan aktual.

Tiga program pengukur G15 memakai studio produksi HTTP di loopback. verify-http mencocokkan isi, MIME dan header. verify-deployment-math menguji tiga kasus clipboard sintetis. preview-export mengimpor fixture publik, mengunduh HTML dari studio, membuka unduhan luring dan memeriksa teks, rumus, tabel, font, worker serta PDF. local-candidate/ memuat file yang diperiksa. Verifikasi G15 memerlukan bukti tersendiri pada URL preview HTTPS yang sebenarnya.

cold-rules.log memuat hasil instalasi baru menggunakan HOME kosong dan PATH build minimal. Probe asal/versi, PDF/HTML, serta 26 aturan penerimaan dijalankan. Lihat keputusan gabungan di ../../acceptance/all-gates.json. Panduan pengumpulan tersedia di docs/ACCEPTANCE_PERANGKAT_HOSTING.md.
