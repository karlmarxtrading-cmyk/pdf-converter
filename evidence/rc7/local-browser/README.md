# Percobaan awal dengan Chromium bawaan

Log di folder ini merekam percobaan pertama dengan biner chromium sistem. Proses tersebut tidak dapat membuat socket yang dibutuhkannya pada lingkungan ini. Pengujian browser dilanjutkan menggunakan pratinjau terkelola, Chromium Headless Shell, Firefox, serta WebKit yang diuji secara terpisah. Status akhir, identitas build dan hasil per tahap ada di `docs/RELEASE_REPORT.md` serta `evidence/rc7/final-results.json`. Kegagalan peluncuran biner awal dihitung sebagai kendala lingkungan.
