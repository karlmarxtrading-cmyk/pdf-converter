# Pembanding

Folder ini memuat pengukuran sebelum kandidat final. Setiap bukti menyimpan identitas yang diukur. Dua percobaan RC8 menggunakan Markdown unggahan yang sama. Pengamat CDP lama memiliki batas 180 detik sendiri sehingga pesan akhir pada tangkapan layar asli tidak dapat disimpulkan dari percobaan itu. Kontrol waktu sintetis terpisah membuktikan mekanisme deadline RC8.
