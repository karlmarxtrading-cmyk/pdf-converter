# Trigonometri: korpus pemeriksaan

## 1. Fungsi trigonometri

| Fungsi | Rumus |
|---|---|
| Sinus | \(\sin\theta=\frac{\text{sisi depan}}{\text{sisi miring}}\) |
| Kosinus | \(\cos\theta=\frac{\text{sisi samping}}{\text{sisi miring}}\) |
| Tangen | \(\tan\theta=\frac{\text{sisi depan}}{\text{sisi samping}}\) |
| Kosekan | \(\csc\theta=\frac{1}{\sin\theta}\) |
| Sekan | \(\sec\theta=\frac{1}{\cos\theta}\) |
| Kotangen | \(\cot\theta=\frac{1}{\tan\theta}\) |

## 2. Identitas trigonometri dasar

Identitas Pythagoras merupakan salah satu rumus paling penting dalam trigonometri.

\(\sin^2(x) + \cos^2(x) = 1\)

\(\sin^2(\text{35}^\circ)+\cos^2(\text{35}^\circ)\approx \text{0,329}+\text{0,671}=1\)

\(\theta\)

θ = 35° | cos θ | = 0.819 | sin θ | = 0.574

Beri masukan

Dua identitas lainnya:

\[ 1+\tan^2\theta=\sec^2\theta \]

\[ 1+\cot^2\theta=\csc^2\theta \]

Identitas hubungan antarfungsi:

\[ \tan\theta=\frac{\sin\theta}{\cos\theta} \]

\[ \cot\theta=\frac{\cos\theta}{\sin\theta} \]

## 3. Lingkaran satuan (Unit Circle)

Lingkaran satuan memiliki jari-jari 1 dan digunakan untuk memahami nilai sinus dan kosinus pada berbagai sudut.

\(x^2 + y^2 = 1\)

\(P(\text{45}^\circ)=(\cos \text{45}^\circ,\sin \text{45}^\circ)=(\frac{\sqrt{2}}{2},\frac{\sqrt{2}}{2})\)
