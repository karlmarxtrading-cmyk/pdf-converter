Panduan PaperForma

PaperForma adalah studio dokumen statis: semua pemrosesan terjadi di browser Anda. Tidak ada akun atau biaya layanan. Batas ukuran masukan dijelaskan saat impor dan di bagian Batas.

Memulai

Buka studio, lalu pilih Buka berkas, Tempel teks, Tempel percakapan, atau Coba contoh. Sumber ada di kiri, pratinjau di tengah, format dan pemeriksaan di kanan. Di layar sempit, gunakan tab Sumber / Pratinjau / Format & periksa.

Baris Alur kerja di atas studio menunjukkan lima langkah — Masukkan → Periksa → Atur gaya → Pratinjau halaman → Simpan HTML / Cetak PDF — beserta statusnya (selesai, belum, perlu perhatian). Klik langkah untuk membuka panel yang sesuai.

Membuka materi

MasukanCatatan
.md, .markdown, .txtUTF-8. BOM dan CRLF dipertahankan pada sumber asli. Mengganti sumber selalu dikonfirmasi dan dapat diurungkan.
.html, .htmBuka dokumen UTF-8. Periksa perubahan isi badan dokumen menjadi Markdown. Pilih Terapkan untuk mengganti naskah, atau Batal untuk tetap di editor. Salinan HTML asli tetap tersedia melalui Lainnya → Sumber asli.
.zipNaskah Markdown + gambar. Bila ada beberapa naskah, Anda memilih satu. Berkas lain dilewati dan dilaporkan. Path berbahaya, symlink, enkripsi, CRC salah, dan rasio kompresi ekstrem ditolak.
PNG, JPEG, WebP, GIF, SVGDitambahkan sebagai aset. Ukuran dibaca dari header sebelum didekode (maks 16.384 px per sisi, 40 MP per gambar, 200 MP per proyek). SVG dibersihkan dari skrip.
.pfprojPaket proyek PaperForma (termasuk dari versi 2.0). Bila ada perubahan belum tersimpan, Anda ditanya dulu.
TempelTeks biasa dan teks terformat. Format HTML hanya dipakai bila teks belum Anda ubah setelah ditempel; perubahan ditinjau dalam diff sebelum diterapkan.

Belum didukung: impor PDF, DOCX/ODT/RTF, dan OCR gambar. Berkas tersebut ditolak dengan pesan khusus.

Percakapan AI

Tempel percakapan (teks biasa dengan label seperti Pengguna:/Asisten:, atau salinan HTML dari aplikasi obrolan). Di tab Pesan Anda dapat memilih pesan, mengubah peran, mengurutkan, memisah, menggabung, lalu memilih bentuk hasil: satu jawaban, pesan terpilih, transkrip, dokumen terkurasi, atau lampiran sumber. Buat dokumen menulis hasilnya ke editor sebagai Markdown yang dapat disunting; percakapan asli tetap tersimpan. Teks di luar penanda pesan tidak dibuang: ia menjadi pesan “Tidak diketahui” yang dapat Anda pilih.

Format dan pengaturan

Empat templat: Modul Belajar (EDU-01), Laporan Eksekutif (BUS-01), Esai dan Bab Panjang (EDT-01), Transkrip Percakapan AI (CON-01). “Terapkan gaya saja” mempertahankan kertas, margin, sampul dan daftar isi Anda; “Pakai rekomendasi format” menerapkan semua bawaan. Pengaturan lanjutan: kertas A4/A5/Letter/Legal, orientasi, margin, huruf, ukuran, spasi baris, sampul, daftar isi, H1 di halaman baru, nomor halaman, kepala/kaki halaman, hemat tinta, bahasa isi, dan brand kit (nama, lembaga, warna, huruf judul, logo, teks kaki). Mengganti format tidak mengubah isi.

Pemeriksaan

Panel Pemeriksaan menampilkan kesiapan terpisah untuk HTML dan Cetak / PDF, terikat revisi yang sedang tampil. Setiap perubahan menurunkan status ke “Memproses” sampai revisi baru selesai. Cakupan: keutuhan isi sumber → keluaran, sintaks rumus, tabel, aset, struktur, keamanan, font; tata letak halaman setelah Periksa halaman (cetak). Semua temuan dapat dijelajah per 100, disaring menurut tingkat dan kategori, dicari, dan diunduh lengkap sebagai JSON. Pemeriksaan ini bukan pemeriksaan fakta.

Ekspor HTML

  • Satu berkas HTML: font dan gambar tersemat, tanpa skrip, dapat dibuka tanpa internet.
  • ZIP HTML: index.html, aset dan manifest.json berisi SHA-256 setiap berkas.
  • HTML publikasi: responsif untuk hosting Anda sendiri; opsional varian daring (gambar https) dan skrip kecil tombol salin kode.

Hasil hanya diserahkan bila semua pemeriksaan wajib lulus. Masalah yang dapat menghilangkan isi (mis. font gagal dimuat, isi berubah) memblokir hasil. Masalah lain (mis. tautan internal rusak, karakter di luar font bawaan) harus Anda setujui secara eksplisit. Hasil, kegagalan dan pembatalan ditampilkan di dalam dialog ekspor.

Cetak / Simpan PDF

Untuk novel atau buku panjang, pilih opsi cetak buku pada panel ekspor. PaperForma menyiapkan berkas HTML cetak lengkap di browser. Setelah siap, Anda dapat mengunduh HTML cetak atau membuka dialog cetak untuk menyimpan PDF. Periksa halaman terakhir, penanda daftar, tabel, dan halaman daftar isi bila diaktifkan. Simpan cadangan .pfproj agar sumber dan setelan dapat dibuka kembali.

  1. Periksa dan ekspor → Cetak / Simpan PDF → Siapkan cetak. Halaman dipaginasi dan isinya diverifikasi terhadap sumber (teks, angka, gambar, rumus, tautan).
  2. Tekan Buka dialog cetak. Pilih tujuan “Simpan sebagai PDF” (atau tujuan PDF di sistem Anda).
  3. Gunakan ukuran kertas dan orientasi yang sama dengan dokumen, skala 100%. Matikan header/footer bawaan browser; aktifkan grafik latar bila tersedia.
  4. Simpan. PaperForma tidak dapat melihat apakah berkas disimpan atau dibatalkan — periksa berkas Anda. Tekan “Cetak lagi” bila perlu.

PDF dibuat oleh mesin cetak browser dari halaman yang disiapkan PaperForma. Setelah dialog ditutup, periksa berkas yang Anda simpan; aplikasi tidak menerima hasil PDF final.

Periksa pratinjau halaman sebelum mencetak. Hasil PDF mengikuti mesin cetak dan pengaturan browser Anda. Tinjau pecahan, pemisahan tabel, nomor halaman, dan bagian terakhir dokumen sebelum menyimpan PDF.

Menyimpan proyek

Status penyimpanan selalu terlihat di samping judul dokumen. Secara bawaan tidak ada yang disimpan (“Belum disimpan”). Pilihan:

  • Simpan paket kerja (.pfproj): cadangan lengkap yang dapat disunting (sumber, input asli, aset, pengaturan, riwayat). Status menjadi “Cadangan diminta”, karena browser tidak selalu dapat memastikan berkas tersimpan.
  • Simpan proyek otomatis di perangkat ini (IndexedDB): status “Menyimpan…”, “Tersimpan di perangkat”, atau kegagalan nyata (gagal, penuh, diblokir, tidak tersedia, konflik dua tab, dihapus di tab lain).

Unduhan HTML atau PDF bukan cadangan proyek. Menutup halaman dengan perubahan yang belum tersimpan memicu peringatan browser.

Urungkan dan riwayat

Urungkan/Ulangi (Ctrl/⌘+Z, Ctrl/⌘+Shift+Z atau Ctrl+Y) mencakup teks, pengaturan, templat, brand kit, percakapan dan gambar. Riwayat revisi menyimpan hingga 100 revisi (6 MiB) dan memulihkan revisi sebagai revisi baru. Input asli tidak pernah ditimpa; lihat lewat Lihat sumber mentah.

Rumus matematika

KaTeX dan font matematika dibundel bersama situs, tanpa ketergantungan CDN. Pembukaan awal aplikasi tetap memerlukan akses ke aset situs; HTML mandiri hasil ekspor membawa fontnya di dalam berkas.

  • Inline: $E_0$ atau \(E_0\); sintaks inline GitHub $`E_0`$ juga dikenali.
  • Display: $$…$$, \[…\] atau blok kode berlabel math. Blok latex/tex tetap ditampilkan sebagai contoh kode.
  • Salinan seperti \\(…\\) dan \\[…\\] dikenali bila isinya menyerupai matematika. Pemulihan karakter salinan dilakukan terbatas; sumber asli tetap ada dan catatan perubahan tampil di Pemeriksaan.
  • Perintah harus termasuk yang didukung KaTeX, seperti \frac, \sqrt, \int, \boxed dan lingkungan matriks. PaperForma bukan mesin seluruh paket LaTeX.

Dari aplikasi AI: tempel teks biasa atau pilih konversi HTML ke Markdown. Bila tersedia, sumber TeX diambil dari anotasi KaTeX/MathJax, atribut data-tex/data-latex, MathML yang menyimpan TeX, atau delimiter literal. Dukungan mengikuti format yang tersalin, bukan nama penyedia AI. Rumus berupa gambar atau widget tanpa sumber TeX tidak dapat dipulihkan persis.

Mata uang ($5 dan $10), URL dan isi kode tetap dilindungi. Rumus yang gagal dirender mempertahankan sumbernya dan menghasilkan temuan. Pemeriksa sisa TeX membantu menemukan sejumlah rumus yang terlewat, tetapi tidak dapat mengenali setiap ekspresi ambigu. Periksa hasil serta catatan pemulihan sebelum mengekspor; pemeriksaan sintaks tidak membuktikan kebenaran matematika.

Batas

  • Masukan yang melewati batas ukuran ditolak utuh, tidak dipotong.
  • Font bawaan mencakup Latin/Indonesia, Yunani, Sirilik dan simbol matematika terpilih. Arab, CJK, Thai, Devanagari, emoji berwarna dan karakter Private Use bergantung font perangkat.
  • Widow/orphan paragraf tidak ditegakkan oleh mesin paginasi; paragraf yang menyisakan satu baris di tepi halaman dilaporkan sebagai catatan. Dua kolom, bagian lanskap, catatan margin, PDF/A/PDF-UA, bookmark PDF: tidak tersedia.
  • Analisis naskah (penguraian, rumus, model keutuhan) berjalan di Web Worker sehingga editor tetap responsif. Paginasi halaman memerlukan DOM dan tetap berjalan di thread utama; pada dokumen ratusan halaman UI dapat tersendat sesaat. Bila Worker tidak tersedia, analisis berjalan di thread utama dengan jeda antar-tahap dan studio menampilkan pemberitahuan.
  • Bila mesin paginasi memutus kata di tengah, tanda hubung tambahan diabaikan dalam pemeriksaan keutuhan; di dalam kode tanda itu dihapus agar kode tidak berubah.

Privasi

Situs hanya mengirim berkas aplikasi. Isi dokumen, clipboard dan berkas Anda tidak dikirim ke server mana pun. Gambar https eksternal hanya dimuat di pratinjau bila Anda mengizinkannya. Data lokal dapat dihapus lewat Penyimpanan & proyek → Hapus semua data lokal.
